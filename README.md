# דשבורד מכירות – Zvikah

דשבורד מכירות אינטראקטיבי המבוסס על דו"ח "WorkflowsExport" שמיוצא מהמערכת (CRM). האפליקציה רצה כולה בדפדפן (client-side בלבד, ללא שרת/מסד נתונים) — הנתונים נשמרים מקומית בדפדפן שלך (`localStorage`) בין שימושים.

## מה יש בפנים

- **כרטיסי KPI**: סה"כ פרמיה צפויה, מספר עסקאות, פרמיה ממוצעת, לקוחות ייחודיים, פילוח לפי סטטוס (הופק/בטיפול/בוטל) עם השוואה לחודש קודם.
- **תרשימים**: מכירות לפי חודש (עם החלפה בין פרמיה/כמות), ביצועים לפי נציג, פילוח סטטוסים, מכירות לפי יצרן ולפי סוג מוצר — לכל תרשים יש גם תצוגת טבלה חלופית.
- **סינון**: טווח תאריכים (כולל presets כמו "החודש"/"30 יום אחרונים"), נציג, סטטוס, סוג תהליך, יצרן, סוג מוצר, וחיפוש חופשי.
- **טבלת נתונים** ממוינת עם עימוד וייצוא ל-CSV של התוצאה המסוננת.
- **עדכון יומי**: כפתור "עדכון דו״ח יומי" מאפשר להעלות את קובץ ה-`xlsx` שמיוצא מהמערכת בכל יום — הוא מחליף את הנתונים הקיימים (כל העלאה נחשבת "תמונת מצב" מלאה ועדכנית).
- מצב כהה/בהיר, תמיכה מלאה ב-RTL, ועיצוב רספונסיבי.

## הרצה מקומית

דורש Node.js גרסה 20 ומעלה.

```bash
npm install
npm run dev
```

האפליקציה תיפתח בכתובת שמודפסת בטרמינל (בדרך כלל `http://localhost:5173`).

## בנייה לפרודקשן

```bash
npm run build
```

התוצר הבנוי (סטטי לחלוטין) ייכתב לתיקיית `dist/`. ניתן לארח אותו בכל שירות אחסון סטטי (GitHub Pages, Netlify, Vercel, S3 וכו') — אין צורך בשרת Node בזמן ריצה.

```bash
npm run preview   # בדיקה מקומית של תוצר הבנייה
```

## איך מעדכנים את הנתונים

1. מייצאים מהמערכת את הדו"ח היומי (`WorkflowsExport`, קובץ `.xlsx`).
2. לוחצים על "עדכון דו״ח יומי" בפינה הימנית העליונה ובוחרים את הקובץ.
3. הדשבורד מנתח את הקובץ, מחליף את הנתונים הקיימים, ושומר אותם בדפדפן (במחשב/בדפדפן הנוכחי בלבד).

הפורמט הנדרש הוא זהה לדו"ח שמיוצא מהמערכת — העמודות מזוהות לפי שם הכותרת (בעברית), כך שגם אם סדר העמודות משתנה בין ייצוא לייצוא, הייבוא ימשיך לעבוד. עמודת חובה: **מספר תהליך**.

> שימו לב: מכיוון שהאפליקציה שומרת את הנתונים ב-`localStorage` של הדפדפן, הנתונים **לא** משותפים אוטומטית בין מכשירים/דפדפנים שונים. כל מכשיר שרוצים להציג בו את הדשבורד צריך לבצע העלאה של הדו"ח בעצמו.

ניתן לשחזר בכל רגע את נתוני הדוגמה (המבוססים על הדו"ח המקורי שצורף) דרך כפתור פח האשפה בכותרת.

## מבנה הפרויקט

```
src/
  types.ts              טיפוסי הנתונים המרכזיים
  lib/                  פענוח קובץ Excel, אגרגציות, פורמט, אחסון מקומי, ייצוא CSV
  hooks/                ניהול מצב הנתונים, ערכת נושא, אנימציית מספרים
  components/           רכיבי ה-UI (כותרת, סינון, KPI, תרשימים, טבלה)
  data/seedData.json    נתוני דוגמה (מהדו"ח המצורף) לשימוש בהרצה ראשונה
```

## טכנולוגיות

React + TypeScript + Vite, Tailwind CSS, Recharts, ו-`read-excel-file` לפענוח קבצי Excel בצד הלקוח.
