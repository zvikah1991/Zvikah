# ויוסי דגים | אתר הזמנות אונליין

אתר הזמנות מקצועי לעסק דגים - מחירון עם תמונות, עגלת קניות, וצ'קאאוט מוכן לחיבור לסליקה. האפליקציה היא פרויקט **נפרד ועצמאי** בתוך הריפו (לא קשור לדשבורד המכירות הקיים בתיקיית השורש).

> ⚠️ **המצב הנוכחי הוא שלד מוכן לפרסום, לא אתר חי לגמרי:**
> - **המחירון** (`src/data/products.ts`) מכיל מוצרים ומחירים **לדוגמה בלבד**, לצורך תצוגה. יש להחליף אותם במחירון האמיתי שלכם (ראו למטה).
> - **התמונות** הן placeholder מעוצב (אייקון + רקע גרדיאנט לכל קטגוריה), עד שתעלו תמונות אמיתיות של המוצרים.
> - **הסליקה** בנויה ומוכנה מבחינת הזרימה (טופס פרטים → סיכום הזמנה → מעבר לתשלום), אבל **לא מחוברת בפועל** לחשבון קארדקום - כי זה דורש שרת + מפתחות API סודיים שלכם (ראו הסבר למטה).

## הרצה מקומית

```bash
cd fish-store
npm install
npm run dev
```

```bash
npm run build     # בנייה לפרודקשן ל-dist/
npm run preview   # בדיקת תוצר הבנייה
```

## איך מעדכנים את המחירון

כל המוצרים מוגדרים בקובץ אחד: `src/data/products.ts`. כל מוצר נראה כך:

```ts
{
  id: "sea-lavrak",        // מזהה ייחודי באנגלית, בלי רווחים
  categoryId: "sea",       // אחת הקטגוריות המוגדרות ב-src/data/categories.ts
  name: "לברק טרי",
  description: "לברק שלם, נקי מקשקשים, מהתפוסה הטרייה של היום",
  unit: "kg",               // "kg" | "unit" | "tray"
  price: 94,                 // מחיר ב-₪
  originalPrice: undefined,  // אופציונלי - למחיר "לפני" במבצע
  tags: ["popular"],         // אופציונלי - "new" | "popular" | "sale" | "premium"
}
```

הקטגוריות עצמן (השמות שמופיעים בתפריט הניווט) מוגדרות ב-`src/data/categories.ts`.

**הכי קל**: תשלחו לי את קובץ המחירון (Excel / PDF / תמונה) ואני אמיר אותו ישירות ל-`products.ts` בשבילכם.

## איך מעלים תמונות אמיתיות למוצרים

כרגע כל מוצר מציג placeholder מעוצב (`src/components/ui/ProductImage.tsx`). כדי לעבור לתמונות אמיתיות:

1. שימו את קבצי התמונות בתיקיית `public/products/` (למשל `public/products/lavrak.jpg`).
2. הוסיפו שדה `image` לכל מוצר ב-`products.ts`, לדוגמה: `image: "/products/lavrak.jpg"`.
3. עדכנו את `ProductCard.tsx` להציג `<img src={product.image} />` כשהשדה קיים, ואחרת ליפול חזרה ל-placeholder.

(אפשר גם פשוט לשלוח לי את התמונות ואני אשלב אותן ישירות.)

## איך מחליפים את הלוגו

הלוגו הנוכחי הוא לוגו טקסטואלי מעוצב (`src/components/Logo.tsx`) - אייקון דג + שם העסק. אם יש לכם קובץ לוגו (SVG/PNG):

1. שימו את הקובץ ב-`public/logo.svg` (או `.png`).
2. עדכנו את `Logo.tsx` להציג `<img src="/logo.svg" />` במקום האייקון המעוצב.

## חיבור סליקה בפועל (קארדקום)

**חשוב להבין**: אי אפשר לחייב כרטיסי אשראי ישירות מהדפדפן בצורה מאובטחת - כי זה ידרוש לחשוף בקוד הציבורי של האתר את סיסמת ה-API הסודית של קארדקום, וכל אחד יוכל לגנוב אותה. זה נכון לכל אתר סליקה בעולם, לא רק כאן.

**מה כן בנוי ומוכן:**
- טופס הזמנה מלא (פרטי לקוח, משלוח/איסוף, סיכום הזמנה) ב-`src/components/checkout/CheckoutPage.tsx`.
- פונקציית לקוח שפונה לשרת סליקה ומפנה את הלקוח לדף התשלום המאובטח של קארדקום: `src/lib/cardcom.ts`.
- **דוגמת שרת מוכנה** ל-API של קארדקום (`LowProfile/Create`): `server/cardcom-create-payment.example.ts`.

**מה נשאר לעשות כדי להפעיל תשלומים אמיתיים:**

1. פתחו חשבון סוחר בקארדקום (אם עוד אין) וקבלו: מספר טרמינל, שם משתמש API וסיסמת API.
2. פרסמו את `server/cardcom-create-payment.example.ts` כפונקציית שרת (למשל Vercel Serverless Function, Netlify Function, או שרת Node/Express קטן). זה חייב לרוץ בצד שרת - **לא** בקוד שרץ בדפדפן.
3. שמרו את מפתחות קארדקום כמשתני סביבה **בשרת בלבד** (לעולם לא במשתנה שמתחיל ב-`VITE_`, כי כל מה שמתחיל ב-`VITE_` נחשף לכל מי שגולש באתר):
   - `CARDCOM_TERMINAL_NUMBER`
   - `CARDCOM_API_NAME`
   - `CARDCOM_API_PASSWORD`
4. עדכנו את `VITE_PAYMENT_API_URL` בקובץ `.env` (ראו `.env.example`) לכתובת שבה פרסתם את פונקציית השרת.
5. בצעו עסקת בדיקה בסביבת ה-Sandbox של קארדקום לפני שמחברים כרטיסים אמיתיים.

עד שהשלב הזה יבוצע, לחיצה על "מעבר לתשלום" בעגלה תציג ללקוח הודעה ברורה שהתשלום עדיין לא זמין באתר, עם מספר טלפון להשלמת ההזמנה טלפונית - כדי שלא תפספסו הזמנות בינתיים.

## מבנה הפרויקט

```
fish-store/
  src/
    types.ts                 טיפוסי נתונים (מוצר, קטגוריה, לקוח)
    data/categories.ts       הגדרת הקטגוריות בתפריט
    data/products.ts         המחירון (מוצרים + מחירים) - כרגע לדוגמה
    lib/format.ts            פורמט מחיר/יחידות
    lib/cardcom.ts           חיבור לקוח לשרת הסליקה
    lib/storage.ts           שמירת עגלת קניות ב-localStorage
    hooks/useCart.tsx        ניהול מצב עגלת הקניות
    components/              רכיבי ה-UI (כותרת, מחירון, עגלה, צ'קאאוט)
  server/
    cardcom-create-payment.example.ts   דוגמת שרת ליצירת עסקת סליקה
```
